Сохранить и перенести прогресс

Откройте «Настройки» → «Данные и справка» → «Создать сохранение»; если файл уже выбран, кнопка называется «Сохранение настроено». Выберите место для файла .aspsave. Приложение будет обновлять выбранный файл после сохранения результатов; состояние записи доступно в диагностике. Копия содержит прогресс и данные тренировок, поэтому передавайте её только тем, кому доверяете. Незавершённая GPS-пробежка не переносится во внешнюю копию. Код восстановления онлайн-ID храните отдельно.

Остановить собственные сетевые функции

Выключите онлайн-режим. В разделе «Облачные сохранения» можно отключить автокопирование или нажать «Отключить облако». Это прекращает соответствующие подключения Aspearan, но не удаляет уже отправленные данные. Если выбранный файл сохраняется через облачный файловый сервис Android, этот сервис может продолжать собственную синхронизацию. Технический обмен Google ML Kit также не управляется переключателем онлайн-режима Aspearan.

Удалить профиль самостоятельно

Откройте «Настройки» → «Данные и справка» → «Удалить профиль». Прочитайте перечень удаляемых данных, нажмите «Удалить профиль полностью» и подтвердите «Удалить навсегда». Если профиль существует только на телефоне, интернет не требуется. Android очищает внутренние данные приложения: игровой профиль и прогресс, историю тренировок, параметры тела, настройки, локальные резервные копии, кэши, диагностику, загруженные материалы, секреты подключений и отметку принятия документов. Приложение закроется; при следующем запуске начнётся первоначальная настройка. Встроенные материалы, поставляемые с установленным приложением, остаются частью приложения.

Как удаляется онлайн-профиль

Если вы подключали онлайн-профиль, на том же экране включите «Включить онлайн для удаления». Введите код восстановления только если приложение утратило доступ к нему. После подтверждения приложение доказывает серверу владение профилем через защищённое соединение. Сервер удаляет профиль, результаты, прогресс кампаний, связи друзей, заявки, уведомления, обращения, жалобы на этот профиль и связанные учётные записи доступа. Затем Android очищает данные приложения на этом телефоне. При ошибке связи не очищайте данные вручную: нажмите «Завершить удаление». Повторный запрос безопасен и не удалит чужой профиль, даже если освободившийся ID уже выдан другому человеку. Старые локальные данные на других ваших устройствах останутся, но доступ к удалённому онлайн-профилю прекратится.

Обращения и подтверждение удаления

Внутренние сообщения становятся недоступны через 30 дней после отправки. Очистка сервера запускается каждую минуту; при сбое физическое удаление может задержаться до восстановления службы. Полное удаление профиля удаляет его внутреннюю переписку и жалобы, где этот профиль указан объектом обращения, независимо от оставшегося срока. Для безопасного повтора удаления при потере ответа сервер на 30 дней сохраняет только технический хеш подтверждения без ника, ID и текста сообщений. Резервные копии и технические журналы инфраструктуры имеют отдельный цикл хранения.

Удалить облачные копии, письма и внешние файлы

Копии в Яндекс Диске, Облаке Mail, ранее использованном Google Диске и файлы, которые вы скопировали самостоятельно, удаляйте средствами этих сервисов. Отключение облака в приложении не стирает его содержимое. Удаление трека из плейлиста Aspearan убирает его из списка, а не удаляет исходный аудиофайл. Письма и Telegram-переписка не относятся к внутренним сообщениям приложения: для удаления копии у разработчика обратитесь к нему, а собственную копию удалите средствами соответствующего сервиса.

Что происходит с игровым ID

Скрытие из рейтинга через 14 дней без открытия рейтинга и изменения результатов не удаляет профиль. Удалить его можно указанной выше кнопкой. После полного удаления обычный ID становится доступен для случайной выдачи новому игроку. Новый профиль имеет отдельную внутреннюю запись и не получает ваши результаты, друзей или сообщения.
